已验证连接/读取、原生节点创建与编辑、删除确认及备份、恢复为副本、Auto Layout、原生渐变与曲线、组件/实例、变量与页面、PNG 图片/资源、自动配对和重开自动在线。用户已确认小状态条尺寸、新版面板和连接设置正常。

- Figma 后台或最小化时原生 PNG 导出可能等待渲染，不保证立即成功。
- 其他客户端未验收，当前发行包仅支持 Windows x64。
- 安装器已在隔离目录测试，不等同于在每台干净 Windows 上完成 Figma/Codex 的首次登录和安装。
- 本次未进行 Figma 社区发布；使用开发插件导入流程。

运行 `pnpm test` 检查源码。`pnpm smoke` 验证本地服务和 MCP 的完整模拟插件链路，需 3055 端口空闲。真实画布脚本应在专用测试文件中运行。
