# FigNexus 验证范围

发布版本：0.3.6。以下区分自动测试、本机实测和未覆盖范围。

## 本次发布检查

- 全局 TypeScript 与独立 Figma 主线程 ES2017 类型检查通过。
- 39 个测试文件、324 项测试通过；覆盖协议、权限、读写、确认删除、备份、渐变、矢量、图片、组件、变量、页面、配对、折叠、安装器和导出任务保留。
- 插件、Bridge、MCP 和配对助手构建通过。
- Windows ZIP 包含运行环境、生产依赖、编译产物、第三方许可、安装器及教程配图。
- 面板与配对图使用真实组件和静态示例数据；无 ID 导入成功提示来自本次真实验证，不含用户工作文件或账户信息。

324 项测试并非 324 次真实 Figma 操作：自动检查使用模拟节点、模拟会话及隔离安装目录。

隔离 Windows 安装实跑通过：首次安装和直接导入说明不需要 ID；0.3.5 升级至 0.3.6 自动复用已有真实 ID；重复安装保持一致；其他 Codex 配置保留；显式 ID 冲突拒绝时原 manifest 不变。用户实际 Codex 配置的前后 SHA256 相同。

## 既有本机真实验收

已验证连接/读取、原生节点创建与编辑、删除确认及备份、恢复为副本、Auto Layout、原生渐变与曲线、组件/实例、变量与页面、PNG 图片/资源、自动配对和重开自动在线。用户已确认小状态条尺寸、新版面板和连接设置正常。

本次实际验证无 ID 开发插件直接导入：Figma 成功提示截图、用户运行后在线、原生只读 ping 成功，编辑权限关闭。导入前后 manifest 的 SHA256 相同，均无 id 字段。首次设置已取消空白插件和 ID 选择步骤；自动复用旧 ID 在隔离安装数据中验收。此次没有修改用户画布。

## 保留的限制

- Figma 后台或最小化时原生 PNG 导出可能等待渲染，不保证立即成功。
- 其他客户端未验收，当前发行包仅支持 Windows x64。
- 安装器已在隔离目录测试，不等同于在每台干净 Windows 上完成 Figma/Codex 的首次登录和安装。
- 本次未进行 Figma 社区发布；使用开发插件导入流程。

运行 `pnpm test` 检查源码。`pnpm smoke` 验证本地服务和 MCP 的完整模拟插件链路，需 3055 端口空闲。真实画布脚本应在专用测试文件中运行。
