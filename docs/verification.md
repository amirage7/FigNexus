# FigNexus 验证范围

发布版本：0.3.9。以下区分自动测试、本机实测和未覆盖范围。

0.3.9 增加四个独立原生绘图入口，在会话未暴露 figma_execute 时仍可创建画框、文字、矩形和批量图层。所有创建经过既有权限、审计和请求ID保护，expectedPageId 在插件执行时验证。安装包同步构建 MCP、Bridge、插件主线程及界面，包含29个工具。

0.3.8 修复了 0.3.7 首次启动将约 665 KB 的完整发行清单误按 64 KB 拒绝的问题。发行清单与安装记录分别保留 8 MiB 和 64 KiB 的大小界限，读取前后均检查。发布构建现在会在压缩前检查完整生产清单的启动规划。
